Built an end-to-end data pipeline synthesising financial data from multiple sources (OSFI, Bank of Canada, StatsCan APIs) into Google BigQuery using Python ETL with scheduled refreshes on Google Cloud. From there, designed fact and dimension tables through dimensional modelling, queried with SQL, and fed the data into a Power BI semantic model with DAX measures, producing a scalable executive dashboard that gives insights regarding which financial institutions should be prioritized for assurance review based on emerging financial risk indicators.
